# Benchmark register

`evidence.csv` is the human-readable claim register. `EVIDENCE_MANIFEST.json` provides the SHA-256 and archive name of each selected bundle in the companion Hugging Face artifact repo.

**These rows must not be collapsed into a single "SHV memory-saving percentage".** The numbers cover subgraph memory, short whole-model memory, persistent optimizer bytes and public loss implementations under different baselines. Check the source ZIP's environment and protocol before comparing runs.\n
