# v0.1.0-research-preview — draft release notes

**Release status: DRAFT, NOT PUBLISHED.** This is the first curated source-and-evidence preview, **not** a drop-in PyTorch/CUDA training-memory package.

## Included

- A technical explanation of consumer-specific saved-state research and its custom-autograd MLP/LN2 prototype.
- Selected experiment sources / output-stripped notebooks, with experiments R5A0, R47, R55, R60 and R62 represented in code or notebooks.
- A small CPU-only tool for inspecting the public fact ledger and verifying result ZIP checksums.
- A separate Hugging Face benchmark-artifact bundle with frozen result archives and per-file SHA-256.
- Negative results: cross-layer XOR (R41), m/v joint lossless encoding (R42), synchronous offload (R43), the EM4 checkpointing comparison (R57) and D9 vs true AdamW8bit (R58-FIX2).

## Key results and boundaries

- **Subgraph only:** R5A0 MLP/LN2 93.11% lower forward-resident allocation and 52.96% lower full-step peak allocation, at roughly 0.46x native throughput.
- **Short whole-model pilot:** R47 EM4+D9 14.70% lower peak allocated than Native+D9 on GPT-2 Small/T4, with substantial slowdown versus ordinary Native training.
- **Public-system optimizer:** R60 tiled/recomputed output cross entropy achieved 28.95% lower peak allocated than full-logits loss in the tested S512 GPT-2 setup (9.84% more step time). R62 subsequently found only ~0.0084% extra memory saving vs Liger. **This is not asserted as SHV-original.**
- **Failed strong baselines:** EM4 lost to native checkpointing in R57; D9 was slower and used more state bytes than actual AdamW8bit in R58-FIX2.

## Known limitations

No generalized inference runtime, no verified 16-to-32 GB equivalence, no long-run equal-quality result, no multi-model proof, and no finished SHV CUDA/Triton runtime. R63 GPU outcome is not included.

CPU source/evidence check: `python -m pip install -e . && python -m shv_preview list`.

GPU reproduction: run a selected Colab notebook using a compatible NVIDIA GPU and compare the generated SHA-256/JSON outputs to the companion artifact repository.
