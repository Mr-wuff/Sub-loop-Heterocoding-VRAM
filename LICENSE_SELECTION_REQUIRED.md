# Software license and patent decision required

This repository is public for research transparency, but **no software LICENSE has yet been selected and no general source-code reuse license is granted** by this repository. Public visibility does not equal open-source licensing.

The separate Hugging Face dataset-type repository currently displays Apache-2.0 in its metadata. That does not automatically license the code here.

Before announcing an OSI-licensed code release, the owner should:
1. Confirm right to publish all code and third-party derived material.
2. Resolve any patent-filing/disclosure timing and choose a software license (e.g. Apache-2.0, MIT, BSD-3-Clause). Apache-2.0 contains express patent terms.
3. Add an exact official LICENSE text and update `pyproject.toml` and README.
4. Approve public author/CITATION metadata and create a real tagged release.

In the meantime, experiments and empirical measurements may be inspected and discussed; redistribution of the software requires permission under applicable law.
